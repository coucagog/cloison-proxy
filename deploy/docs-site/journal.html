Transparence · preuve sans donnée vue

Le journal qui prouve que personne ne lit.

Chaque fenêtre d'audit y est enregistrée : des compteurs k-anonymisés, signés par le contrôle, liés en chaîne de hachage. Aucun texte, aucune PII — preuve sans donnée vue (invariant I9).

Vérification
La chaîne est validée dans votre navigateur (WASM cloison-verify) : aucune donnée ne quitte la page, aucune confiance n'est demandée.

1 · Accéder au journal

Le journal public vit sur journal.wonkom.ai — page de vérification interactive + données brutes :

RessourceContenu
https://journal.wonkom.aipage : état de la chaîne, verdict, preuve d'inclusion
https://journal.wonkom.ai/ledger.jsonlles entrées brutes (genèse + séquence)
https://journal.wonkom.ai/control_pubkey.hexla clé publique du contrôle (Ed25519)

2 · Comment c'est construit

  • Append-only : chaque entrée lie la précédente par prev_hash ; la signature Ed25519 du contrôle scelle l'ensemble.
  • Contenu : des compteurs k-anonymes par type de PII (CniSn, Email, PhoneSn, Gazetteer nom/ville…), par tenant, par fenêtre — jamais de texte, jamais de compteur isolé < k.
  • Chaîne de hachage : toute altération — même d'un octet — casse la chaîne. La vérification re-compute genèse, séquence, hachages et signatures, depuis la genèse jusqu'à la tête.
  • Preuve d'inclusion : un payload_hash figure-t-il dans le journal ? Calculé dans votre navigateur.

3 · Vérifier soi-même (sans la page)

# Récupérer le journal et la clé publique :
curl -s https://journal.wonkom.ai/ledger.jsonl -o ledger.jsonl
curl -s https://journal.wonkom.ai/control_pubkey.hex -o control_pubkey.hex

# Vérifier la chaîne avec le CLI (ou le WASM sur la page) :
cloison-cli ledger check            # ok=true · N entrées · head_seq=…
# Alternative : la page web fait la même vérification en WASM, localement.

4 · Ce que le journal ne contient pas

  • Aucun texte client : ni messages, ni extraits, ni valeurs.
  • Aucun compteur isolé < k : les cellules sous le seuil de k-anonymat sont redactées (prouvé en conditions réelles : une cellule brute = 1 est sortie à 0).
  • Aucun secret : ni jetons, ni clés, ni hash de données personnelles.
